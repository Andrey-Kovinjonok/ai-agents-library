# Правила проекта

## Назначение

- Это общая библиотека для агентских инструментов на Node.js. Не сводить её к
  одному модулю путей.
- Общий механизм размещать здесь только тогда, когда его действительно должны
  одинаково использовать несколько продуктов.
- Логику индексов, веток и предметных настроек оставлять в GitNexus, CodeGraph
  или другом продукте-владельце.
- Исключение по прямому требованию пользователя: общие чистые правила выбора
  веток из targets находятся в branch-targets. Точное специальное обозначение
  — __CURERNT__; current является настоящим именем ветки. Настройки, вызовы Git,
  существование ссылок, запуск и сохранение индексов остаются у продукта.
- Общий git-checkout содержит технические операции чтения Git и подготовки
  отдельного снимка без файлов окружения. Он не выбирает базовый индекс,
  не запускает инструменты и не меняет исходный репозиторий.

## Данные и границы

- У каждого продукта отдельный корень `~/.agents/skills/<product>` и отдельный
  `config.json`.
- Не создавать общий список проектов между продуктами.
- Не записывать служебные файлы в рабочий проект, путь которого передан
  библиотеке.
- Настройки читать с диска при каждом разрешении проекта; не вводить скрытый
  долгоживущий кеш.
- Не удалять старые места автоматически. Разрешены только обнаружение и отчёт;
  очистка требует отдельного решения пользователя и выполняется продуктом.

## Изменения

- Перед изменением контракта сначала обновить локальную модель данных и
  проверяемые сценарии в `.ai-design/triz/agent-library/design-state.md`, создав
  файл при его отсутствии. Каталог `.ai-design` не публикуется.
- Исправление ошибки начинать с проверки, которая её воспроизводит.
- Не добавлять сторонние зависимости без явного согласования.
- Проверки не должны обращаться к настоящему `~/.agents` и не должны изменять
  сторонние рабочие проекты.
