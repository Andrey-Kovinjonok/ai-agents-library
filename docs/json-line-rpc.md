# Общий обмен сообщениями с дочерним процессом

Модуль json-line-rpc реализует JSON-RPC 2.0 (JavaScript Object Notation Remote
Procedure Call — вызов операций сообщениями с номером запроса). Один объект
передаётся одной строкой. Это не диспетчер индексов и не реестр проектов.

## Данные и ответственность

- JsonLinePeer принимает читаемый и записываемый потоки; хранит ожидающие ответы
  по номеру запроса только в памяти экземпляра. Обработчик операции задаёт продукт.
- request(method, params, options) ожидает ответ; notify(method, params) отправляет
  уведомление без ожидания ответа. Ограничение ожидания по умолчанию — 60 секунд.
- maxMessageBytes ограничивает размер сообщения; по умолчанию 16 МиБ. Неверные
  сообщения и закрытое соединение завершают ожидающие запросы ошибкой.
- spawnJsonLinePeer(command, args, options) запускает явно выбранную программу
  без командной оболочки. options.env обязателен: библиотека не передаёт всё
  окружение родителя автоматически. Выбор cwd и разрешённых переменных у продукта.
- close закрывает поток и ждёт собственный процесс; затем при необходимости
  посылает ему сигналы завершения. Другие процессы не затрагиваются.

Ограниченная диагностическая часть stderr (standard error — отдельный поток
сообщений об ошибках) сохраняется в памяти. Постоянного журнала, фонового демона,
автоматической установки и отправки статистики в этом модуле нет.

## Подключение

    import { JsonLinePeer, spawnJsonLinePeer } from "ai-agents-library";

Продукт самостоятельно проверяет происхождение программы, фильтрует операции,
выбирает внешнее поколение и добавляет сведения о проекте в результат.
Библиотечный транспорт этих гарантий не заменяет.

## Проверки и выпуск

    node --test test/json-line-rpc.test.js

Проверяются обмен и несколько одновременных запросов, уведомления, ошибка
обработчика, закрытие/неверное сообщение и границы размеров/времени ожидания.
Подробные названия проверок находятся в тесте. Настоящие домашние настройки
и корпоративные проекты не используются.

Изменение локальное и ещё не выпущено отдельной меткой. В текущей разработке
оба продукта используют явно настроенную локальную связь с библиотекой.
