# Выбор веток: branch-targets

## Назначение и владельцы

Одинаково интерпретировать список `targets` у GitNexus, CodeGraph, Graphify и
других продуктов. Продукт хранит настройки в собственной записи проекта своего
`~/.agents/skills/<product>/config.json`, перечитывает их при каждом действии и
передаёт библиотеке свежие сведения о выбранной рабочей папке Git.

Модуль ничего не читает и не пишет на диск, не запускает команды, не обращается
в сеть и не держит скрытое состояние. Это не общий диспетчер или реестр проектов.

## Формат записи проекта

```json
{
  "directory": "projects/frontend_of_work_andreykovinenok",
  "targetsVersion": 2,
  "targets": ["__CURERNT__", "origin/beta"]
}
```

`targetsVersion` относится только к трактовке целей, а не к версии всего конфига.
Без версии 2 функция отказывает: прежнее значение `current` нельзя молча
переосмыслить. Пустой список означает отсутствие целей; скрытого выбора main нет.

| Значение | Смысл |
| --- | --- |
| `__CURERNT__` | Выбранная ветка именно той рабочей папки, сведения о которой переданы |
| `current`, `Current`, `CURRENT` | Обычные имена, регистр сохраняется |
| `refs/heads/__CURERNT__` | Настоящая локальная ветка, имя которой совпало с обозначением |
| `beta` | Локальная ветка beta |
| `origin/beta` | Удалённая ветка, если origin есть в переданном списке remotes |
| `refs/remotes/origin/beta` | Явная полная ссылка на удалённую ветку |
| `refs/heads/origin/beta` | Локальная ветка с буквальным именем origin/beta |

Написание `__CURERNT__` закреплено по требованию пользователя, намеренно не
заменяется на `__CURRENT__`. Последнее также является буквальным именем ветки.
Для имени источника со сложной структурой можно передать полную refs/remotes/...
ссылку; массив remotes принимает только имена без косой черты.

## Вызов

```js
import { resolveBranchTargets } from "ai-agents-library/branch-targets";

const selected = resolveBranchTargets({
  targetsVersion: 2,
  targets: ["__CURERNT__", "origin/beta", "current"],
  currentBranch: "feature/task",
  remotes: ["origin"],
});
```

Результат содержит три цели: `refs/heads/feature/task`, `refs/remotes/origin/beta`
и `refs/heads/current`. Поля каждого результата:

- `requestedTargets: string[]` — исходные обозначения, объединённые в эту цель.
- `kind: "local" | "remote" | "detached"` — локальная, удалённая ветка или
  выбранный снимок без привязки к ветке.
- `branch: string | null` — настоящее локальное имя, имя вида origin/beta либо null.
- `ref: string` — HEAD для выбранной локальной ветки, иначе полная ссылка или
  полный номер отдельного снимка. Перед выполнением продукт должен убедиться,
  что ветка/номер не изменились после наблюдения.
- `branchKey: string` — полная ссылка или commit:<номер>; идентификатор, НЕ путь.
- `workingTree: boolean` — учитывать содержимое выбранной рабочей папки, включая
  её незакоммиченные изменения; их безопасное чтение организует сам продукт.

Совпадающие цели объединяются по полной ссылке с сохранением порядка первого
появления. `beta` и `__CURERNT__` объединятся, если выбрана beta; `origin/beta`
останется отдельной. Реальная выбранная ветка с именем current корректно
разрешится и через current, и через __CURERNT__ без потери её рабочего содержимого.

Если выбрана не ветка, а отдельный снимок, передать `currentBranch: null` и
`currentCommit` — полный шестнадцатеричный номер из 40 или 64 знаков. Без номера
указатель текущего состояния отклоняется: общий ключ HEAD смешал бы разные снимки.
Заданные ветки без указателя могут разрешаться без номера текущего снимка.

Неправильные типы, скрытые символы, пробелы, выражения наподобие main~1, ссылки на
метки выпуска и неоднозначные сокращения HEAD не поддерживаются. Имена не
обрезаются и не исправляются молча. Проверка консервативная; существование ссылок
и возможность их использования остаются обязанностью продукта.

## Совместное использование с настройками продукта

```js
import { resolveProductProject, resolveBranchTargets } from "ai-agents-library";

// Внутри обработки каждого нового события:
const { mapping } = resolveProductProject(product, checkoutPath);
const selected = resolveBranchTargets({
  targetsVersion: mapping.targetsVersion,
  targets: mapping.targets,
  currentBranch: gitObservation.currentBranch,
  currentCommit: gitObservation.currentCommit,
  remotes: gitObservation.remotes,
});
```

Переменные product, checkoutPath и gitObservation предоставляет продукт; это
образец подключения, а не утверждение, что все инструменты уже подключены.
Для настройки определяется основной проект, но файлы для индексации читаются
из checkoutPath (фактически выбранной рабочей папки), не из основной папки.
Если работают несколько рабочих папок, продукт собирает сведения обо всех;
один вызов функции сам их не обнаруживает.

## Явный переход старых настроек

Старая общая интеграция внутри AI-POOL понимала `current` как указатель.
Пока работает её старый обработчик, менять живой список на новый нельзя:
он сочтёт __CURERNT__ обычной веткой. Сначала требуется подключить новый
продуктовый обработчик и проверить его, затем согласованно изменить настройки.

```js
import { migrateLegacyBranchTargets } from "ai-agents-library/branch-targets";

const converted = migrateLegacyBranchTargets(
  { targetsVersion: 1, targets: oldMapping.targets },
  { confirmCurrentSelector: true },
);
const nextMapping = { ...oldMapping, ...converted };
// Предъявить различия. Сохранение файла выполняет продукт после разрешения.
```

Функция возвращает только `{targetsVersion: 2, targets: [...]}` и не изменяет
входные данные. Старый current заменяется на __CURERNT__. Прежняя настоящая
ветка __CURERNT__ сохраняется как refs/heads/__CURERNT__. Остальные поля записи
нужно сохранить через объединение, как показано выше. Версия 1 здесь явно
устанавливается продуктом, который распознал прежний формат, а не угадывается.

## Что сюда не входит

Получение изменений Git, поиск исходной ветки, копирование базового индекса,
достраивание графа, блокировки баз, запуск индексаторов, удаление и защита
активных индексов. Выбор целей уже общий; общая политика защиты от удаления
пока спроектирована отдельно и ещё не реализована.
