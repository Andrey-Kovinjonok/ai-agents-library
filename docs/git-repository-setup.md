# Подключение удалённого Git-репозитория

## Репозиторий на GitHub

Создан пустой репозиторий:

```text
https://github.com/Andrey-Kovinjonok/ai-agents-library-
```

README, `.gitignore` и лицензия MIT уже подготовлены локально. Поле
`private: true` в `package.json` запрещает случайную публикацию в общий реестр
пакетов npm, но не управляет видимостью репозитория на GitHub.

Адрес Git для первого отправления:

```text
https://github.com/Andrey-Kovinjonok/ai-agents-library-.git
```

Из корня библиотеки выполняются:

```sh
git remote add origin https://github.com/Andrey-Kovinjonok/ai-agents-library-.git
git push -u origin main
```

Если GitHub-репозиторий всё же был создан с собственным начальным коммитом, не
применяйте принудительную отправку. Сначала нужно получить серверную историю и
согласовать объединение.

## Подключение к нашим веткам продуктов

GitNexus и CodeGraph должны получать библиотеку непосредственно из Git по
неизменяемой метке выпуска. Пример записи в `package.json` продукта для первого
выпуска:

```json
{
  "dependencies": {
    "ai-agents-library": "git+https://github.com/Andrey-Kovinjonok/ai-agents-library-.git#v0.0.1"
  }
}
```

`v0.0.1` — метка первого выпуска, которая навсегда указывает на один конкретный
коммит. Перемещать или повторно использовать опубликованную метку нельзя.
Исправление получает новую метку, например `v0.0.2`. Обновление выполняется
отдельным изменением зависимости и файла фиксации зависимостей каждого продукта
после прохождения его тестов.

Для закрытого репозитория машине сборки и разработчика потребуется настроенная
авторизация GitHub. Локальный путь `file:` как постоянный способ подключения не
используется: он привязал бы сборку к одной машине.

## Что входит в удалённый репозиторий

В Git отправляются исходники, определения типов, тесты, документация, правила
агентов и автоматическая проверка GitHub. Локальная `.ai-design` намеренно
игнорируется: в ней остаются проектный журнал и аудит с абсолютными путями.

Настоящий адрес удалённого репозитория записан в `package.json`.
