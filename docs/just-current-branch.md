# __JUST_CURRENT_BRANCH__

Новый единственный target выбирает текущую ветку и добавляет storageMode:
just-current. branchKey содержит настоящее имя; отделённый HEAD содержит
идентификатор коммита. Старый __CURERNT__ не изменён.

Продукты GitNexus, CodeGraph и Graphify используют постоянную папку
branches/just-current/generations/current. Снимок обновляется на месте,
базы не копируются в новые поколения. Неизменённые исходные файлы не
записываются; добавленные и изменённые записываются; отсутствующие удаляются
только из служебного снимка. Источник и его Git не изменяются.

При смене ветки или исходного коммита обращение к инструменту сначала обновляет
индекс. При прежнем содержимом и той же ветке явное обновление пропускает движок.
Движки сами управляют записью базы; объём записи не обещается побайтово.
Чтение после неудачного обновления запрещено до успешного повторного анализа.
История очищенного служебного Git содержит изменения файлов, а не копии баз.

2026-10-05: во всех существующих записях продуктов enabled:true, targets:[];
исключения Strata и PlatformHft получают новый маркер. Старые индексы не удалены.
Подключения Codex уже enabled:true. Полные реальные проекты строятся при первом
обращении. Уже запущенные процессы должны получить новое соединение, чтобы
загрузить изменённый код; изменение настроек само по себе код не перезагружает.

Проверки: 83 теста библиотеки; отдельные испытания настоящих трёх движков
с переключением ветки, неизменным временем записи старого файла, добавлением,
удалением, автоматическим обновлением перед чтением и восстановлением после
сбоя. Проверки прежних поколений и публичных входов всех продуктов также прошли.
